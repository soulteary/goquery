# v1.14.1

## Changes

- Handle filtered `AddBack` calls on initial selections without a previous selection.
- Prevent `AddNodes` and `Slice` results from overwriting related selections through spare slice capacity.
- Update `golang.org/x/net` from v0.62.0 to v0.63.0.
- Update `github.com/soulteary/cascadia` from v1.0.0 to the published v1.1.0 selector engine.
- Pin reporting to Go 1.27.4 and update checkout, setup, and artifact action pins.
- Include the previously merged report-branch publication and bootstrap fixes ([PR #10](https://github.com/soulteary/goquery/pull/10), [PR #11](https://github.com/soulteary/goquery/pull/11)).

The selection fixes are adapted from upstream commits
[a7078d9](https://github.com/PuerkitoBio/goquery/commit/a7078d92876e75451aa75fd3f4b3ff73ae1828ca),
[94ea86e](https://github.com/PuerkitoBio/goquery/commit/94ea86e3dc7f3cb9f09108c451ed7fb5ebb601ed),
[1f518ef](https://github.com/PuerkitoBio/goquery/commit/1f518ef4ef58faa5f62d0e0262096d0bcb864ceb), and
[132cedf](https://github.com/PuerkitoBio/goquery/commit/132cedf99cf651f40f69b7adcc84cb7b29e3ac87).
Their regression tests are retained with this fork's import paths. The
`AddNodes` regression also exercises an externally supplied node slice with
spare capacity, independently of the `Slice` capacity limit.

## Validation

The dependency update uses the public cascadia v1.1.0 module and checksum
database. Its source revision is `253aa3ebb8b172e7958d90c286d89c2470c70061`.
Local validation uses Go 1.27.4 for module verification, uncached race tests
with full statement coverage, `go vet`, and a consumer smoke test of the
new selectors. The minimum/current Go compatibility matrix and quality
checks are required on the final reviewed PR revision before merging.

## Compatibility

Go 1.26 remains the minimum supported version. This release retains the
`github.com/soulteary/goquery` module path and the fork's selector-generation
and node-traversal APIs.

The cascadia v1.1.0 upgrade adds `:is()`, `:where()`, `:any-link`, explicit attribute `s`
flags, and filtered sibling selectors. Its `:enabled` correction stops matching
links merely because they have `href`; use `:link` or `:any-link` for that case.
See the [selector-engine release](https://github.com/soulteary/cascadia/releases/tag/v1.1.0).
